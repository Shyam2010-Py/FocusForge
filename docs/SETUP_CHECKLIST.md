# Setup checklist

- [x] Create the GitHub repository `FocusForge`.
- [x] Upload the initial Android project and Supabase migration.
- [ ] Confirm GitHub Actions completes `Android CI`.
- [ ] Create a Supabase project.
- [ ] Run `supabase/migrations/001_initial_schema.sql` in SQL Editor.
- [ ] Configure project URL and publishable key as local properties or GitHub Actions secrets.
- [ ] Review RLS policies with at least two test accounts before enabling multiplayer.
- [ ] Test timer pause/resume and app process death on a physical Android device.
